# Tipos de gráficos
Outra forma de se representar uma distribuição de dados é o gráfico.
É muito comum nos depararmos com gráficos no cotidiano. Eles trazem um grande facilitador visual para a compreensão
daquilo que está sendo apresentado.
Muitos meios de comunicação utilizam os gráficos como forma de aproximar o espectador ou leitor daquela informa-
ção que se pretende divulgar ou discutir.
Mesmo para esse tipo de representação encontram-se formas variadas de o fazer. Os tipos de gráficos notáveis de
que trataremos são o gráfico de barras (horizontais e verticais), o gráfico de setores (pizza), o gráfico de linhas (poligonal)
e o plano cartesiano.
